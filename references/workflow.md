# 内部输出结构与工作流程

以下是本技能的制作记录 schema，不是 H3 API schema。可用 Markdown 表格或 YAML 表达；未知值用 null，空数组表示明确没有，不能混用。

| 字段 | 类型与要求 |
|---|---|
| project / scene / clip | 稳定字符串 ID |
| mode | text / first_frame / first_last / last_frame / full_reference |
| target | 平台、版本、时长秒数、画幅；每项附 confirmed/assumed/unknown |
| sources | 素材 ID、文件位置、用途、是否实际查看 |
| characters | 角色 ID、已确认外貌、发型、服装、声音、参考素材；未知不补造 |
| look / camera_setup | 内部记录：成像档位、可选设备/镜头、机位、运镜、对焦与材质；不作 API 参数 |
| lighting / optics / composition | 内部记录：照明方向与补光、设备参考和可见效果、人物主次与空间层次；不作官方字段 |
| library_matches | 适用素材 ID、采用内容、舍弃项与改写原因；空数组表示未匹配 |
| speaker_map | 本片段 S 编号到角色 ID 的映射 |
| continuity_in | 时间、地点、布光、屏幕方向、视线、站位、左右手道具、情绪、已知剧情 |
| shots | 镜头 ID、起止秒、景别、机位、运镜类型/幅度/速度、动作阶段、对白、同期声 |
| audio | 连续环境声、局部声响时点、配乐或明确无配乐 |
| continuity_out | 计划末态、实际末态、下一镜入口；未生成时实际末态为 null |
| prompt | 模式名称及对应提示词文本，独立于上述内部字段 |
| validation | pass / needs_revision / unverified，附具体原因 |

## 分解步骤
先列剧情事件和情绪转折，再分镜；切镜服务于信息或情绪，不机械按秒切换。保留台词原文，试读估时，并留出呼吸、反应和转身时间。超时优先拆片；不擅自删改关键对白。

动作写为：起始支撑与姿态 → 动作发起 → 接触/受力/位移 → 松手或停止 → 稳定末态。描述有意义的肢体关系，不为每个关节编造运动指令。

运动路径必须说明人物相对场景固定物的位置、屏幕移动方向、使用哪只手、绕行或接触对象。画面左右与人物自身左右分别写清。手机在右耳时不能又用右手拉帘，除非显式换手。站起时先建立脚底支撑；避免瞬移和无过渡姿态跳变。

尾帧先检查与首帧的身份、服装、光线、机位、空间是否兼容。矛盾时说明冲突并建议换帧、拆镜或显式转场；不声称提示词能消除几何冲突。尾段可预留稳定停留，但一秒只是可调经验，不能强制每片使用。

连续镜头记录镜轴和视线：对话两人保持屏幕侧别；越轴必须有可见过渡。切近景仍继承手持物、帘子开合、人物朝向和情绪进度。实际成片最后一帧只能在检查后作为下一片首帧。

声音按层处理：对白属于具体镜头事件；脚步和帘轨声与动作对齐；整体环境声贯穿；收音机音乐属于画内声，钢琴配乐属于画外声。用乐器、速度、力度与进入/退出时机描述配乐，避免只有情绪词。

## 素材使用与模式核对
先读取 h3-rules.md，选定模式再提取相应格式。素材库只提供场景与摄影内容，不覆盖模式语法。有图像帧锚定时先检查模式对齐首行；连续动作阶段不自动编号为多个 Shot。内部音频配置区分对白、背景人声、非语言声音、环境声与画外配乐，不能只用一个含糊的无人声标记。

## 提交前清单
- [ ] 素材已查看，未查看项和假设已披露；无虚构既有角色设定。
- [ ] 片长与平台模式已核验，或清楚标记待核验。
- [ ] 起止时间递增、无意外重叠，动作和对白有足够时间。
- [ ] 一个角色对应稳定身份；片内说话人不换号；对白原文和语言正确。
- [ ] 人物手部、道具、空间、光线和末态能连续衔接。
- [ ] 运镜不同时要求锁定机位和跟拍；镜头变化与人物位移分开写。
- [ ] 首尾帧之间有可实现路径；末态冲突已处理。
- [ ] 环境声、配乐、对白职责分清；无音乐不等于全静音。
- [ ] 复制区没有内部 schema、检查项或未替换占位符。
- [ ] 模式格式有对应证据；未声称精确嘴型、身份或尾帧保证。
- [ ] 对应图生模式的对齐首行、图片顺序、尾镜编号与时长已核对；仅正文模板不可冒充完整输出。
- [ ] 已排除原素材妆容服饰绑定，设备型号未编造；当前参考图的人物一致性仍保持。
- [ ] 微动作数量适合时长，持机手与空闲手不冲突；连续动作未误写为剪辑。
- [ ] 噪点/清晰度、美颜/微纹理、固定机位/运动和允许人声范围无矛盾。
- [ ] 只使用匹配场景的方法，没有把其他场景的配乐、字幕或画质禁令继承为全局规则。

诊断记录格式：片段/时间点 | 观察或用户报告 | 预期 | 偏差 | 可能原因（假说） | 单变量修订 | 下次验收标准。嘴型问题先检查台词长度、说话人、遮挡与音轨，再考虑拆镜；人物漂移先缩减遮挡和复杂转身、复核参考；运镜失败先简化幅度；尾帧失败先检查路径和时间。

## 第二批素材专项检查
- [ ] 灯光比较只调整获准的照明；新片段的首帧锚点与照明变化没有冲突。
- [ ] 可见光束、眩光、反射与轮廓高光有光源/介质/几何依据，不是固定贴图。
- [ ] 设备版本、卡口和覆盖范围的未知项已说明；焦距、景深、透视和画幅没有混用。
- [ ] 主次、人数、握持、视线和遮挡连续；前景不挡关键脸部或动作。
- [ ] 已将静帧构图补成可执行的视频过程；没有把截图重构文字称作原始参数。
- [ ] 只有当前用户选择时才加入朝代、服饰、血污、武器、字幕黑边或CG风格。
