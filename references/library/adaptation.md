# 可自定义槽位、冲突处理与调用示例

来源：用户 U20261106-01 加本技能整理。以下为内部配置约定，不是 H3 schema 或新控制字段。

## 自定义槽位
| 要素 | 每次从哪里确定 | 未指定时 |
|---|---|---|
| 身份、年龄、外貌、妆容、发型、服饰 | 当前参考图与用户描述 | 需要时补问，不能继承示例造型 |
| 地点、天气、光线、道具、人物关系 | 当前剧情和参考图 | 补问影响动作与情绪的项目 |
| 情绪、视线对象、微动作 | 当前剧情节点 | 提出少量可选建议，不默认撩人 |
| 成像风格 | 干净手机/低照度/轻美颜/电影/其他 | 问一个方向，随后协调其参数 |
| 摄影系统、机身型号、镜头型号 | 用户指定或后续设备素材 | 不虚构型号；可以用泛化设备描述 |
| 焦距、光圈、快门、帧率、曝光 | 只有影响目标画面时才用 | 描述可见效果，避免无意义参数堆叠 |
| 分辨率、画幅、片长 | 当前平台可用选项与用户目标 | 标注待核验，不继承 720p 或固定秒数 |
| 声音、字幕、UI、标志 | 当前用户要求 | 不继承素材中全局禁令；按目标提出建议 |

具体设备型号后续可扩充为条目，记录机身、镜头、想模拟的可见特征和来源。型号仅是提示词参考，不意味着模型执行真实硬件模拟。若要陈述某设备的真实参数，查官方文档；不把某种焦距、光圈和手机前摄硬性拼在一起。焦距影响视场；实际构图还与画幅、距离有关，不用单个数字承诺效果。

## 声音范围先分开
- 无对白：人物不说话；环境中是否允许模糊人群声、笑声、呼吸需另定。
- 无语言性人声、保留身体声音：不说话、不唱、不哼、不含糊念音节，也不保留背景人群说话；可显式保留轻微呼吸、衣物摩擦和脚步。
- 无可辨台词、允许远处人群：只有用户选择此范围才保留模糊人声；不能同时写禁止任何人声。
- 无任何人类声音：去掉对白、背景人声、哼唱、笑哭及可闻呼吸，仍可有车辆、风雨、物体声。
- 全静音：所有声音都关闭，才将 overall_soundscape 设为 N/A。无画外音乐单独在 non_diegetic_music 中处理，按 h3-rules.md 执行。

无发声的角色不分配 S 编号；非语言呼吸放在相应声音描述里。说话/旁白时继续保留 H3 的语言标签、编号及时间线规则。无配乐但有车流/脚步时不能把声景也写 N/A。

## 冲突处理顺序
1. 当前用户明确要求优先决定内容；模式对应官方规范决定表达格式。
2. 检查人物与道具是否能按物理关系完成动作，区分摄像机运动与人物运动。
3. 检查质感、声音、机位、时长是否互相冲突；原始材料冲突说明见批次记录。
4. 关键冲突先补问；非关键选择提供并标注建议。绝不照抄互相冲突的禁止项。
5. 列出所参考条目 ID、采用的部分与被舍弃的不适用部分，保持最终提示词简洁。

只选一种主运镜，再选择兼容的视角/景别/对焦与必要质感。确需复合运动时按时间阶段描述。例：固定机位可搭配转移焦点；完全静止不能同时持续手持晃动；保持焦距不变不能同时变焦。默认把升降与俯仰、环绕与原地翻滚区分。

## 素材召回与适配示例
例 1：用户说“随手自拍，靠近镜头后看我一眼，真实一些”。
匹配 SELFIE-01、MICRO-01、LOOK-01；先补问参考身份、画质方向、片长/输入模式与声音范围中的关键缺项。不自动给角色化固定妆容，不默认夜街、眨眼、拨发或无配乐。

例 2：用户说“雨中人物背对镜头向远处走，镜头越拉越远”。
匹配 CAM-B03 或 CAM-H07，加 REAL-02。先确认希望跟随人物保持距离，还是让人物逐渐缩小；后者不能同时要求主体始终同样大小。不从自拍例继承手机噪点。

例 3：用户说“固定机位，焦点从桌上的信转到后面的人，电影真人感”。
匹配 CAM-A01、CAM-H04、REAL-01/02；相机位置固定，改变焦平面。根据景别选可见质感，不自动塞入全程锐利、自动对焦搜索或重压缩。需要对白时保留说话人和 d 标签，不能沿用自拍无人声设置。

例 4：用户说“先不要写成片提示词，把这组相机/运镜例子加入技能”。
走素材收录入口，保存通用方法、关键词、来源和适用条件并更新索引；不启动场景补问，也不把素材内容当作当前拍摄要求。
